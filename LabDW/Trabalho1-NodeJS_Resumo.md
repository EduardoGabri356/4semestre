### **Introdução laboratório de DesenvolvimentoWeb**

#### O que é o Node.JS?

&#x09;Começando do princípio, nos anos 2000 pessoas desenvolvedoras sempre procuravam soluções para criar aplicações escaláveis, rápidas e seguras, tanto no front-end quanto no back-end, o Javascript rodava essencialmente apenas no navegador e o navegador não permite que você faça muitas coisas porque naquela época não havia como acessar arquivos locais. Assim, Ryan Dahl queria executar o mesmo código no frontend e no backend, Ryan entrou no código-fonte do Chrome e arrancou o interpretador Javascript, ele conectou uma maneira simples de carregar bibliotecas e implementou o básico de um sistema de biblioteca base estilo Unix (sistema de arquivos, sockets, esse tipo de coisa). Ele lançou a primeira versão do ambiente de execução em 2009 combinando o motor V8 do Google com uma arquitetura de E/S assíncrona orientada a eventos e liberou em código aberto, nascendo assim o Node.JS



#### Para que serve o Node.JS?

&#x09;Com a nova possibilidade de usar o Javascript separadamente no backend, juntamente com a popularização dos smartphones, o uso intensivo das mídias sociais e o crescimento das soluções de IoT, o node veio como uma solução poderosa e barata para a criação e a manutenção de ambientes de tecnologia com altas demandas. Em resumo, ele permite usar JavaScript para criar servidores web, APIs, aplicações em tempo real, é possível criar aplicações completas, rodando diretamente no servidor, sem depender do navegador.



#### Principáis características

* Escalabilidade: entrega soluções para arquiteturas escaláveis;
* Multiplataforma: criar desde soluções web a aplicações desktop;
* Open Source: código aberto, o que nos possibilita contribuir com o projeto e até mesmo realizar customizações;
* Multi-paradigma: podemos adotar várias formas de codificar usando paradigmas como a orientação a objetos, o funcional e o orientado a eventos.
* Vantagens excepcionais: extremamente leve, muito rápido por conta do motor V8 do google, usa JS
